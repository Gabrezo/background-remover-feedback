# Background Remover for Figma — feedback

Public issue tracker for [Background Remover by Gabrezo](https://gabrezo.com).

- 🐞 **Bugs / feature requests** — open an issue here.
- 💬 **Quick questions** — https://discord.gg/sVB4sbJaby
- ✉️ **Private / license issues** — support@gabrezo.com

When reporting a bug, please include: Figma desktop version, plugin version,
which model you used (Fast / Balanced / Detailed / Cloud), and what the result looked like.
